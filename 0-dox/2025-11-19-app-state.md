# Application State - 2025-11-19

## Overview
**Publix** is a modern credential search platform that has been modernized from a legacy Django/Python application to a full-stack Next.js application with a Neo4j graph database. The application provides a secure, searchable interface for encrypted credential data with advanced filtering, visualization, and import/export capabilities.

## Architecture
The application follows a monolithic architecture within the Next.js framework, leveraging API routes for backend logic.

1.  **Client Layer**: React components using MUI for styling. Communicates with API routes via Axios.
2.  **API Layer**: Next.js API routes (`pages/api/*`) handle requests, authentication, and validation.
3.  **Data Access Layer**: Direct Neo4j driver integration for executing Cypher queries.
4.  **Database Layer**: Neo4j stores data in a graph structure (TLD -> Domain -> ContentLine).

## Key Features
- **Credential Search**: Advanced search with filters for TLD, domain, email, date ranges, and password presence.
- **Data Management**: Full CRUD (Create, Read, Update, Delete) operations for content.
- **IntelX Integration**: Automated data ingestion and direct search via IntelX API.
- **Dashboard**: Analytics dashboard showing data distribution and trends.
- **Graph Visualization**: Interactive graph view of TLDs, domains, and their relationships.
- **Security**: AES-256-GCM encryption for sensitive data; Role-based access control.
- **Import/Export**: Bulk CSV/JSON import and export functionality.

## Database Schema
The graph data model consists of:
- **Nodes**:
    - `TLD`: Top-Level Domain (e.g., "com")
    - `Domain`: Second-Level Domain (e.g., "google.com")
    - `ContentLine`: The actual credential record (encrypted)
    - `User`: Application users for authentication
- **Relationships**:
    - `(:TLD)-[:HAS_DOMAIN]->(:Domain)`
    - `(:Domain)-[:HAS_CONTENT]->(:ContentLine)`

## Project Structure
- `frontend/`: Main application source code.
    - `pages/`: Routes and API endpoints.

    - `scripts/`: Database initialization cypher scripts.

## Configuration
Configuration is managed via `.env` file (see `.env.example`):
- Neo4j connection details (URI, User, Password)
- Encryption keys (Key, Salt)
- IntelX API credentials
- NextAuth settings
